# Sales, Payment & Delivery Plan

## 1. Recommended: Stan Store or Gumroad (set up in ~30 minutes)

Both take payment and **automatically deliver the file** after purchase. No coding, no manual emailing.

| | Stan Store | Gumroad | Stripe Payment Link |
|---|---|---|---|
| Setup | Link-in-bio store | Product page | Payment link only |
| Auto-delivery | Yes | Yes | Needs extra (Zapier/email) |
| Payouts | Bank / Stripe | Bank / PayPal | Bank |
| Best for | Instagram/TikTok sellers | Simplest start | Existing website |

Check each platform's current fees on its pricing page before choosing. I haven't verified current rates.

**Steps**
1. Export `01-the-15-minute-agent.md` to PDF (Claude can produce a designed PDF/Canva version).
2. Create a Gumroad or Stan account; connect your bank/Stripe for payouts.
3. New product, upload the PDF, set price, paste the sales copy below.
4. Set a post-purchase message (delivery email below). The platform sends the download link automatically.
5. Buy it yourself with a discount code to test the full flow.
6. Add terms: no refunds policy or a 7-day guarantee (your call), plus the disclaimer.

**Pricing suggestion:** $19–$29 launch price (comparable agent-AI guides surfaced in search at ~$14–$20, e.g. a $19.99 Getly playbook and a $14 prompt pack). Optional $49 bundle with a template Notion/Docs pack.

## 2. Sales Page Copy

**Headline:** Stop Writing the Same Listing Description Four Times.
**Sub:** 7 copy-paste AI workflows built for working Realtors. Set up in 20 minutes.

- Build your SOUL file so AI sounds like you, not a robot
- Four buildable AI assistants: transactions, content, referrals, listing presentations
- Morning Briefing that plans your day
- Listing launch: MLS copy + social + sphere email in one run
- Speed-to-lead replies that sound like you
- Sphere texts people actually answer
- Transaction deadline tracker
- Fair Housing and privacy guardrails
- 30-day adoption plan

**Who it's for:** Agents who want less admin and more conversations.
**Who it's not for:** Anyone expecting AI to find clients for them. It saves time; you still do the relationships.

**Honest note:** No income promises. Results depend on how you use it.
